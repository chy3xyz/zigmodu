# Life Phase 1 实施计划：core + file adapter + CLI + CI 钩子

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 落地 spec（`docs/superpowers/specs/2026-10-16-life-issue-release-design.md`）的 Phase 1——共享 core（状态机/校验/ID/reproBlock/since/fingerprint）+ file adapter（`.life/` markdown 存储）+ `zmodu life` CLI 子命令 + `zmodu ci --life` 钩子。

**Architecture:** core（纯 Zig 无 IO，零依赖）放框架 `src/life/`，经 `src/life.zig` barrel 导出；CLI 通过"第三个显式模块 import"拿到 core（与 `module_graph`/`test_collection` 同款双 build.zig 接线）；file adapter 与命令实现放 CLI 侧 `tools/zmodu/src/life.zig`（`runAt(io, alloc, args, dir)` 可测模式，照 verify/doctor 先例）。

**Tech Stack:** Zig 0.17.0（std.Io 模式）· std.crypto sha256 · 零新依赖。

## Global Constraints

- Zig **0.17.0 正式版**；禁 `std.fs`、`std.Thread.sleep`、`ArrayList.init`；文件 IO 一律 `std.Io.Dir.cwd()` + 每操作传 `io`；`ArrayList(T).empty` + 显式 allocator。
- 构建/测试一律 `export ZIG_GLOBAL_CACHE_DIR=$PWD/.zig-global-cache`；测试过滤 `zig build test -Dtest-filter=life`（CLI 测试同样挂在根 test step，filter 生效）。
- **test-collection 门禁**：每个带 test 的新文件必须在某个已被收集文件的 test 块里 `_ = @import(...)`——框架注册点 `src/tests.zig:9-13` 风格；CLI 注册点 `tools/zmodu/src/main.zig:957-961` 风格。漏注册时 `bash scripts/check-test-collection.sh` 会点名文件。
- 零新依赖（build.zig.zon dependencies 保持 `.{}`）。
- CHANGELOG 条目：英文正文 + 中文标题；提交消息先写 `/tmp/<n>_msg.txt` 再 `git commit -F`（heredoc 在本环境会炸）。
- 版本号不动（0.39.13）；破坏性：否。
- 手拼 JSON 必须转义（`jsonEscape` helper，本仓库审计已把"手拼 JSON 未转义"列为缺陷类）。
- 每任务一个提交，前缀 `feat(life):` / 最后任务收尾 `批 182：...`。
